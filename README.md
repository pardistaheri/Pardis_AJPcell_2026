This folder contains MATLAB codes for the computational models of the lung of control, hyperoxia-tolerant(H-T), and hyperoxia-susceptible(H-S) mitochondrial respiration and bioenergetics. The codes are in 2 branches; the “enzyme parameter estimation” branch is the optimization and estimation of intrinsic parameters of mitochondrial enzymatic reactions and transporters. The main branch is zipped into three files for the three folders corresponding to the control H-T and H-S. Each folder is the estimation of the extrinsic parameters of these groups. Each folder contains subroutines of the mitochondrial enzymes and transporters based on estimated parameters in the “enzyme parameter estimation”. Each folder also contains MATLAB codes to generate the figures of the published manuscript in the American Journal of Physiology-Cell Physiology.
In each folder add the directory of Enzyme folder to addpath line in Read_Condt.mat
